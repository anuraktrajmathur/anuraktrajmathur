# 🧪 Featured Projects

## 🔹 [Vehicle Dynamics & Yaw Stability Dashboard](https://github.com/anuraktrajmathur/vd_dashboard)

An interactive high-fidelity vehicle dynamics dashboard developed using Python and Streamlit for real-time visualization of:

- Yaw Stability Control (YSC)
- Nonlinear Pacejka Tire Dynamics
- Vehicle Handling Characteristics
- Stability Envelope Analysis
- ESC Intervention Logic
- Tire Force Generation
- Sideslip & Yaw Response

### Highlights
- Nonlinear 2-DOF vehicle model
- Predictive ESC controller
- Interactive simulation controls
- Real-time plots & analytics
- Futuristic engineering dashboard UI
- Animated welcome screen & custom visual identity

---

## 🔹 [MPC-Based Steering Simulation in Python + Blender](https://github.com/anuraktrajmathur/mpc_steering_simulation)

A vehicle path-tracking simulation using a kinematic bicycle model with steering control and Blender visualization.

### Features
- Sine-wave trajectory tracking
- Python-based simulation
- CAD vehicle animation in Blender
- Real-time trajectory visualization

---

## 🔹 [Speed Sign Recognition using CNN](https://github.com/anuraktrajmathur/CNN_model)

Traffic sign recognition system using a Convolutional Neural Network (CNN) trained on the GTSRB dataset.

### Features
- Real-time webcam inference
- Speed sign classification
- Image preprocessing pipeline
- Contour-based detection

---

## 🔹 [Vehicle Modelling & Behaviour Assessment](https://github.com/anuraktrajmathur/vehicle_modelling)

A single-track (bicycle) vehicle model used to compare linear and nonlinear tire dynamics.

### Features
- Pacejka tire model
- Yaw rate analysis
- Body slip dynamics
- Lateral acceleration response
- Tire force characterization
